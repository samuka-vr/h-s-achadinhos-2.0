# Comece aqui

1. Não envie este ZIP diretamente para hospedagem sem extrair.
2. Extraia a pasta completa.
3. Crie um projeto no Supabase.
4. Preencha `.env.local` usando `.env.example`.
5. Execute as migrations `001` a `008` na ordem.
6. Rode `npm install` e `npm run dev`.
7. Abra `/studio/login`, crie a primeira conta e depois `/studio/bootstrap`.
8. Cadastre produtos reais no H&S Studio.
9. Teste tudo em preview.
10. Publique na Vercel somente após `npm run verify`.

Leia também `docs/MOBILE-SETUP.md` para fazer o processo pelo celular.
