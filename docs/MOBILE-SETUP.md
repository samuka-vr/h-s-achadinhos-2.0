# Configuração pelo celular

O caminho mais simples no celular é:

1. Extraia o ZIP no gerenciador de arquivos.
2. Envie todos os arquivos para um repositório GitHub.
3. Crie o projeto no Supabase pelo navegador.
4. Abra o SQL Editor e execute cada migration em ordem.
5. Importe o repositório na Vercel.
6. Adicione as variáveis de `.env.example` na Vercel.
7. Abra o domínio de preview e configure a primeira conta em `/studio/login`.

Para desenvolvimento local pelo celular, Termux funciona melhor que editores que não executam Node.js.
